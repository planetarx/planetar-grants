# Schmidt Marine Technology Partners — program facts

Research note on Schmidt Marine Technology Partners (SMTP) ocean-innovation funding.
Verified 2026-07-02 against schmidtmarine.org and press coverage.

## At a glance

| Field | Value | Source |
|---|---|---|
| Funder | **Schmidt Marine Technology Partners**, a program of The Schmidt Family Foundation | schmidtmarine.org |
| Model | "Venture philanthropy" — grants for early development of ocean technologies | schmidtmarine.org |
| **Window** | Initial-proposal portal **open 2026-06-01 → closes 2026-07-31** | schmidtmarine.org/proposals |
| Grant size | typically **US$100,000–$400,000** (development, testing, deployment) | Terra Viva / fundsforNGOs summaries |
| Selectivity | ~**10%** of reviewed projects funded | same |
| Eligible | Universities, non-profits, **startup companies — globally** | same |
| Scope | Practical, scalable **hardware or software** improving ocean health | same |
| Portal | https://schmidtmarine.secure-platform.com/a (login-gated; form fields unverified) | search result |

## Focus areas (theirs) → planetar mapping

| SMTP focus | planetar fit |
|---|---|
| **Sustainable fisheries** | Dark-vessel detection + re-identification = the IUU-fishing enforcement gap; detect vessels operating with AIS off in closed/protected areas |
| **Ocean observing** | Open real-time fusion of AIS + Sentinel-1 SAR + EO cameras + hydrophones; novel use of existing sensor streams |
| Habitat health | Secondary: pollution (bilge-dump) monitoring, marine-mammal protection (acoustic) |
| Network support (tools that strengthen the marine-tech ecosystem) | The open bus + typed envelope as shared infrastructure other ocean-tech projects can build on |
